# Portfolio - Leonel Ibarra

Este es mi portfolio personal desarrollado con **Vue 3** y **Vite**, donde presento mi trayectoria como Desarrollador Full Stack, mis habilidades técnicas y contribuciones.

## 🚀 Tecnologías Principales

- **Frontend:** Vue 3 (Composition API), Vite, Sass, Bootstrap 5.
- **Backend (Experiencia):** PHP (Laravel, CakePHP), Python (Django).
- **Infraestructura & Herramientas:** Docker, Git (GitHub, GitLab, Bitbucket), CI/CD, Nginx, Apache.

## ✨ Características

- **Presentación:** Breve resumen profesional y enlaces a redes sociales.
- **Experiencia Profesional:** Línea de tiempo interactiva detallando proyectos en el sector público y privado.
- **Stack Tecnológico:** Sección de habilidades categorizada (Frontend, Backend, DevOps, Herramientas).
- **Contribuciones:** Visualización de actividad y contribuciones en GitHub.
- **Contacto:** Acceso directo a perfiles profesionales y métodos de contacto.

## 🛠️ Instalación y Configuración

Para ejecutar este proyecto localmente, asegúrate de tener instalado [Node.js](https://nodejs.org/).

1. **Clonar el repositorio:**
   ```bash
   git clone <url-del-repositorio>
   cd portfolio
   ```

2. **Instalar las dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

## 📂 Estructura del Proyecto

- `src/Components/`: Componentes modulares (Timeline, Skills, etc.).
- `src/Components/Icons/`: Librería de iconos SVG personalizados.
- `src/styles.scss`: Estilos globales utilizando preprocesador Sass.
